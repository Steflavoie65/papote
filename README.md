# Projet Papote

Application mobile pour aider les personnes âgées à sortir de la solitude.

## Structure du projet

- **papote-senior**: Application mobile destinée aux personnes âgées
- **papote-famille**: Application mobile destinée aux familles et proches
- **papote-shared**: Code partagé entre les deux applications

## Objectifs

- Faciliter la communication entre les personnes âgées et leurs proches
- Fournir une interface adaptée aux besoins spécifiques des seniors
- Créer un lien intergénérationnel simple via la technologie

## Installation et démarrage

```bash
# Pour l'application Senior
cd papote-senior
yarn install
yarn start

# Pour l'application Famille
cd papote-famille
yarn install
yarn start
